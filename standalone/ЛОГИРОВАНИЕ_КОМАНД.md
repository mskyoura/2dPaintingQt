# Логирование в executeMultipleCommand, executeSingleCommandWithRetries и sendSingleCommand

## Добавлено логирование успешного выполнения команд

В методы `PBsetup::executeMultipleCommand`, `PBsetup::executeSingleCommandWithRetries` и `PBsetup::sendSingleCommand` добавлено логирование для отслеживания успешного выполнения команд для каждого устройства.

### Что добавлено:

#### В `executeMultipleCommand`:
```cpp
// Log successful execution for debug mode
if (pWin && pWin->wAppsettings && pWin->wAppsettings->getIsDebug()) {
    QString methodName = pWin->cmdFullName(cmdType);
    QString deviceInfo = QString("устройство %1 (%2)").arg(donor._ID()).arg(pWin->getPBdescription(vmIndex));
    QString logMessage = QString("Метод %1 выполнен успешно для %2").arg(methodName).arg(deviceInfo);
    
    if (pWin->log) {
        pWin->log->appendLog(logMessage);
    }
}
```

#### В `executeSingleCommandWithRetries`:
```cpp
// Для _STATUS команд:
if (anyAttemptSucceeded && cmdType == _STATUS) {
    // Log successful execution for debug mode
    if (pWin && pWin->wAppsettings && pWin->wAppsettings->getIsDebug()) {
        QString methodName = pWin->cmdFullName(cmdType);
        QString deviceInfo = QString("устройство %1 (%2)").arg(donor._ID()).arg(pWin->getPBdescription(vmIndex));
        QString logMessage = QString("Метод %1 выполнен успешно для %2").arg(methodName).arg(deviceInfo);
        
        if (pWin->log) {
            pWin->log->appendLog(logMessage);
        }
    }
    return true;
}

// Для других команд (перед вызовом executeStatusCommandAfterSuccess):
if (cmdType != _STATUS) {
    // Log successful execution for debug mode before status check
    if (pWin && pWin->wAppsettings && pWin->wAppsettings->getIsDebug()) {
        QString methodName = pWin->cmdFullName(cmdType);
        QString deviceInfo = QString("устройство %1 (%2)").arg(donor._ID()).arg(pWin->getPBdescription(vmIndex));
        QString logMessage = QString("Метод %1 выполнен успешно для %2").arg(methodName).arg(deviceInfo);
        
        if (pWin->log) {
            pWin->log->appendLog(logMessage);
        }
    }
    return executeStatusCommandAfterSuccess(serialPort, vmIndex, it, donor);
}
```

#### В `sendSingleCommand`:
```cpp
// Log successful command sending for debug mode
if (bytesWritten != -1 && pWin && pWin->wAppsettings && pWin->wAppsettings->getIsDebug()) {
    QString methodName = pWin->cmdFullName(cmdType);
    QString deviceInfo = QString("устройство %1 (%2)").arg(donor->_ID()).arg(pWin->getPBdescription(donorVmIndex));
    QString logMessage = QString("Метод %1 выполнен успешно для %2").arg(methodName).arg(deviceInfo);
    
    if (pWin->log) {
        pWin->log->appendLog(logMessage);
    }
}
```

### Условия логирования:

- ✅ **Только при включенном `isDebug = true`** в settings.ini
- ✅ **Только при успешном выполнении команды** (когда методы возвращают `true`)
- ✅ **Для каждого устройства отдельно** в циклах обоих методов

### Примеры сообщений в логе:

```
Метод Проверка статуса выполнен успешно для устройство 1 (ПБ-001)
Метод Запустить Реле2 выполнен успешно для устройство 2 (ПБ-002)
Метод Включить Реле1 выполнен успешно для устройство 3 (ПБ-003)
Метод Выключить Реле1 выполнен успешно для устройство 4 (ПБ-004)
```

### Поддерживаемые команды:

- `_STATUS` - Проверка статуса
- `_RELAY1ON` - Включить Реле1
- `_RELAY1OFF` - Выключить Реле1
- `_RELAY2ON` - Запустить Реле2

### Расположение в коде:

**Файл:** `pbsetup.cpp`  
**Методы:** 
- `PBsetup::executeMultipleCommand` (строки 1599-1608)
- `PBsetup::executeSingleCommandWithRetries` (строки 1708-1718 и 1723-1734)
- `PBsetup::sendSingleCommand` (строки 935-944)

### Логика работы:

#### executeMultipleCommand:
1. 🔄 **Цикл по устройствам** в `executeMultipleCommand`
2. 🎯 **Вызов** `executeSingleCommandWithRetries` для каждого устройства
3. ✅ **Проверка успеха** - если команда выполнена успешно
4. 🔍 **Проверка флага** `isDebug` в настройках
5. 📝 **Запись в лог** с полным названием команды и информацией об устройстве

#### executeSingleCommandWithRetries:
1. 🔄 **Цикл попыток** для выполнения команды
2. 🎯 **Вызов** `readSingleResponse` для каждой попытки
3. ✅ **Для _STATUS:** логирование и возврат `true` при успехе
4. ✅ **Для других команд:** логирование перед вызовом `executeStatusCommandAfterSuccess`
5. 🔍 **Проверка флага** `isDebug` в настройках
6. 📝 **Запись в лог** с полным названием команды и информацией об устройстве

#### sendSingleCommand:
1. 🔧 **Подготовка команды** - формирование параметров и команды
2. 📝 **Логирование запроса** (если включено обычное логирование)
3. 📤 **Отправка команды** через serial port
4. ✅ **Проверка успеха** - если `bytesWritten != -1`
5. 🔍 **Проверка флага** `isDebug` в настройках
6. 📝 **Запись в лог** с полным названием команды и информацией об устройстве
